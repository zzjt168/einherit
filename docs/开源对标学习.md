## 产品原则（从开源共识提炼）

1. **不宣布身故**：超时只升级「联系确认」，不自动开放全部资产。
2. **冷静期**：报备点过后先 `grace_hours`，再外呼/通知备用联系人。
3. **紧急取用要等**：受益人申请 → 等待 N 天 → 主人可拒绝；到期未拒绝才放行只读交割。
4. **可审计**：关键动作写 `audit_log`。
5. **可打印交付**：执行人场景往往要纸质/PDF，不能只靠 App 在线。
